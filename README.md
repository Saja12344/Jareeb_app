# Jareeb App

A SwiftUI application prototype for browsing places, books, interests, and saved content. The repository contains multiple SwiftUI screens and sample content models.

## Run locally

Open the Swift files in an Xcode app project on macOS, select an iOS simulator, and run with `⌘R`.

## Repository structure

- `ContentView.swift` and screen files — SwiftUI views
- `book*.swift` — sample book content
- `place*.swift` — sample place content
- `Assets.xcassets/` — app assets

This is a prototype; replace sample content and review navigation before production use.
